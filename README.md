# StudyPilot AI 🎓🤖
StudyPilot AI is an AI-powered study planner that helps students generate personalized, adaptive study schedules based on their subjects, difficulty levels, available study time, and deadlines.

## 🚀 Features
- AI-generated personalized study plans
- Adaptive rescheduling when tasks are skipped
- Focus mode with countdown timer
- Progress tracking and insights
- Responsive student-friendly UI

## 🛠 Tech Stack
- HTML, CSS, JavaScript
- PHP
- MySQL
- AI API (for planning and prioritization)

## 📂 Project Structure
- `/api` – Backend endpoints
- `/assets` – CSS, JS, images
- `/includes` – Database & AI logic
- `/sql` – Database schema

## ⚙️ Setup Instructions
1. Clone the repository
2. Import `sql/database.sql` into MySQL
3. Configure database connection in `includes/db.php`
4. Add your AI API key securely
5. Run on localhost or deploy
